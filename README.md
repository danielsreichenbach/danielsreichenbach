## Rumba Identity

Founder of [Rumba Identity](https://github.com/rumba-id) — an open-source, Rust-based alternative to Azure AD/Entra ID. Protocol-compatible (OAuth2, OIDC, SCIM, Graph API), deployable anywhere, with device management and conditional access. → [rumba.id](https://rumba.id)
